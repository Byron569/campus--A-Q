## 四、DR-15 单独说明（执行修复时的新发现）

**问题**：DR-01 裁决「阈值只作用于向量路」后，检索结果可能出现三类切片：

| 来源 | 有余弦相似度？ |
| --- | --- |
| 仅向量路命中 | ✅ 有 |
| 两路都命中 | ✅ 有 |
| **仅 BM25 命中** | ❌ **没有** |

而 FR-09 要求引用卡片显示「文档名 + 原文片段 + **相似度分数**」。第三类切片的分数无法给出。

**处理决定（PM 判断，客户可在下次评审推翻）**：

1. `SearchHit` 增加 `matched_by` 字段（`vector` / `bm25` / `both`），`score` 允许为 `None`。
2. 界面表现：
   - `matched_by = vector` 或 `both` → 正常显示相似度数字（如 `相似度 0.82`）
   - `matched_by = bm25` → **不显示数字**，改显示标签「关键词命中」
3. 理由：**宁可少显示一个数字，也不编造一个数字**。这与项目「不编造、可核验」的基调一致；同时给了用户一个有用的信号——这条来源是靠精确关键词匹配到的，而非语义相近。

> 该决定不改变任何需求，只补充了接口字段与界面表现，属设计细节。
