## 1. 设计源说明

| 项 | 内容 |
| --- | --- |
| 设计库 | Doubao Design Library |
| 产品类型 | AI dashboard |
| 视觉调性 | minimal / cool-toned / technical / calm（极简、冷色调、技术感、克制） |

## 2. 与项目的适配点（必须先看）

模板定位是「英文 AI Dashboard」，我们做的是「中文校园知识库助手」。有 6 处必须适配，否则直接照搬会出问题。

| # | 冲突 | 模板原值 | 我们的处理 | 影响 |
| --- | --- | --- | --- | --- |
| A-01 | **语言** | 定位 `en`，字体栈只有 `Stack Sans Text, ui-sans-serif, system-ui` | **补中文字体**：`"PingFang SC", "Microsoft YaHei", "Noto Sans SC"`（呼应 macOS / Windows 双平台） | 不加会导致中文回退到系统默认，字重与行高不统一 |
| A-02 | **圆角过大** | `--radius: 1.2rem` = 19.2px，全站统一 | 拆成三级派生令牌：控件 10px、卡片 14px、胶囊 999px | 19.2px 用在输入框/标签上会显得过圆，中文界面更明显 |
| A-03 | **间距过密** | `--spacing: 0.24rem` = 3.84px，dashboard 高密度 | **不全线套用**。正文区用 8/12/16/24px 常规节奏，仅在表格与列表行内用 4px 级 | 照搬会让中文段落挤成一团，可读性崩 |
| A-04 | **无阴影** | 所有 shadow 令牌不透明度为 0，纯边框分隔 | 保留「边框优先」，但**取消 Streamlit 默认卡片阴影与描边样式** | Streamlit 原生带阴影，不覆盖会破坏模板调性 |
| A-05 | **暗色模式机制不同** | 用 `.dark` 类切换 | **客户裁决：不做暗色模式，仅浅色** | 省掉双写映射与两套配色的维护成本；Streamlit `base` 固定 `light` |
| A-06 | **图表色是单色系梯度** | `--chart-1..5` = `#557fff → #002e7d`，同一蓝色 5 级 | **只用于表示「程度」**（如引用相似度）；**禁止用于区分类别**（新生/行政/课程） | 5 个梯度都是蓝，用来区分分类会认不出；分类改用文字标签 + 图标区分 |

> **A-06 是硬约束，写进实现规则**：`--chart-*` 在本项目只承担「强度/程度」编码，不承担「类别」编码。

> **A-07：模板缺少状态语义色。** 模板只定义了 `destructive` 一个语义色，没有 success / info，导致「入库完成」「入库中」这类状态无合适颜色。本项目**新增两个语义色令牌**（`--success` `#16a34a`、`--info` `#0ea5e9`），色相与模板主体蓝色协调，不破坏调性。这是**对模板的扩展而非替换**，改动已登记在 DR-02。

| 侧边栏面 | `--sidebar` | `#eff1f4` | 左侧导航背景 |
| 侧边栏选中 | `--sidebar-accent` | `#d4daff` | 导航选中项 |

### 3.2 暗色模式（❌ 本期不做）

**客户裁决：只做浅色模式，不提供暗色切换。** 相关需求同步调整：

- FR-26 设置页：**移除「主题切换」**，保留改显示名 / 改密码 / 注销入口
- FR-29 界面主题：降级为「浅色主题的配色与 CSS 定制」，不含深浅色切换

模板自带的 `.dark` 令牌保留在 `docs/design/doubao/colors_and_type.css` 中**作为未来备查**，本项目不实现、不引用。

> 影响：`--primary` 在深底对比度不足的问题（原 D-01）随之消失，不再需要处理。

### 3.3 图表 / 程度梯度（仅浅色）

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--chart-1` | `#557fff` | 强度最高（例：相似度 ≥0.8） |
| `--chart-2` | `#0065fd` | 高（0.6~0.8） |
| `--chart-3` | `#0057da` | 中（0.4~0.6） |
| `--chart-4` | `#0043ad` | 低（0.2~0.4） |
| `--chart-5` | `#002e7d` | 最低（<0.2） |

> 再次强调 **A-06 硬约束**：这 5 个值是同一蓝色的深浅梯度，**只表示程度，不表示类别**。

## 4. 排版

### 4.1 字体栈

```css
--font-sans: "Stack Sans Text", "PingFang SC", "Microsoft YaHei", "Noto Sans SC",
             ui-sans-serif, system-ui, -apple-system, "Segoe UI", Roboto, sans-serif;
--font-serif: "Source Serif 4", "Songti SC", serif;   /* 仅用于「关于」页引言，可选 */
--font-mono:  "JetBrains Mono", ui-monospace, "SF Mono", Menlo, Consolas, monospace;
```

> `Stack Sans Text` 为模板自带字体，中文界面下实际生效的会是 PingFang SC（macOS）/ Microsoft YaHei（Windows）。

### 4.2 字号阶梯（模板未提供，本项目自建）

模板只给了字体族，没给字号。以下阶梯按「中文可读性优先」自建：

| 角色 | 字号 / 行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| 页面主标题 | 24 / 34 | 600 | 页面顶部标题 |
| 区块标题 | 18 / 28 | 500 | 卡片标题 |
| 小标题 | 15 / 24 | 500 | 列表分组、表单分组 |
| 正文 | 14 / 22 | 400 | 主体内容（基准字号） |
| 辅助文字 | 13 / 20 | 400 | 说明、时间、来源 |
| 标签/徽标 | 12 / 18 | 500 | 状态标签、分类标签 |
| 代码/数值 | 13 / 20 | 500 | 相似度分数、文件名（`--font-mono`） |

> 中文基准字号取 **14px**（而非英文常用的 13px），行高 ≥1.5，避免中文显示拥挤。

## 5. 间距、圆角、阴影

### 5.1 间距（适配后）

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--space-1` | 4px | 图标与文字、标签内边距 |
| `--space-2` | 8px | 按钮组、紧凑元素间距 |
| `--space-3` | 12px | 输入框内边距、表单行距 |
| `--space-4` | 16px | 卡片内边距、常规元素间距 |
| `--space-6` | 24px | 区块间距 |
| `--space-8` | 32px | 页面级留白 |

> 模板的 `--spacing: 3.84px` 仅保留给「表格行内 / 列表行内」这类高密度场景，不作为全局节奏（见 A-03）。

### 5.2 圆角（适配后，替代模板单一 19.2px）

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--radius-control` | 10px | 按钮、输入框、下拉框 |
| `--radius-card` | 14px | 卡片、面板、弹窗 |
| `--radius-pill` | 999px | 状态标签、分类标签、头像 |

### 5.3 阴影

模板策略是**纯边框分隔，不用阴影**（所有 shadow 令牌不透明度为 0）。本项目沿用，但有两处例外与要求：

| 场景 | 处理 |
| --- | --- |
| 卡片 / 面板 / 表格 | 一律 `1px solid var(--border)`，**不加投影** |
| **二次确认弹窗**（注销 / 删除 / 禁用） | **允许一层轻阴影表达层级**（客户已确认，D-02） |
| Streamlit 默认卡片 | **必须覆盖掉其自带描边与阴影**，否则调性不一致 |

轻阴影取值：`0 8px 24px rgba(14, 17, 21, 0.10)`，仅在弹窗遮罩层内的容器上使用，不作为卡片常规样式。

## 6. 组件映射（模板 → 本项目）

| 模板组件 | 模板用途 | 本项目落点 |
| --- | --- | --- |
| `button`（primary / secondary / ghost / destructive） | 主次操作 | 登录 / 注册 / 上传 / 重试 / 保存（primary）；取消 / 启用（secondary）；删除 / 禁用 / 注销（destructive） |
| `search-input` | 紧凑查询框 | 文档列表筛选、用户列表搜索 |
| `app-card` | 内容卡片 | **引用来源卡片**（文档名 + 片段 + 相似度）、文档信息卡 |
| `sidebar-nav` | 仪表盘导航栏 | 左侧主导航（问答 / 我的文档 / 管理员 / 设置 / 关于） |
| `data-table` | 密集数据表 | 文档列表、用户列表、入库任务列表 |
| `chat-composer` | AI 输入区 | **问答输入框 + 发送按钮**。**分类过滤不放在输入框的「工具行」**，统一放页面顶部工具栏（Streamlit 里输入框内嵌工具行不做，见 DR-09） |

**风格继承规则**（来自模板 crossComponentPatterns）：

1. 圆角统一取自共享圆角令牌，不做混搭。
2. 保持紧凑密度，用低调的垂直节奏。
3. **用边框分隔，不用阴影**。
4. 主操作用品牌蓝，次操作用中性面，破坏性操作才用 destructive。

## 8. Streamlit 落地映射

Streamlit 的主题能力分两层：`config.toml` 能配一部分，剩下的必须注入 CSS。

### 8.1 `.streamlit/config.toml`（能配的部分）

```toml
[theme]
base = "light"
primaryColor = "#0065fd"
backgroundColor = "#ffffff"
secondaryBackgroundColor = "#eff1f4"
textColor = "#0e1115"
font = "sans serif"

[server]
address = "0.0.0.0"
port = 8501
# 注意：这里要比业务上限（20MB）宽，给业务层留出校验空间。
# Streamlit 在上传阶段就会拦截超限文件，不会进入我们的代码，
# 若设成 20，用户看到的是「整批上传失败」，违反 FR-05「单文件失败不影响同批」（见 DR-03）。
maxUploadSize = 25
```

> `config.toml` **不支持**圆角、边框、阴影、间距、暗色模式的自定义值切换，这些全部走 CSS 注入。

### 8.2 `src/ui/theme.py`（必须注入 CSS 的部分）

| 覆盖项 | 原因 |
| --- | --- |
| 卡片圆角与描边 | 模板要求 14px + 1px 边框，Streamlit 默认不是 |
| 去掉卡片阴影 | 模板为无阴影设计（A-04） |
| 按钮圆角与高度 | 模板为 10px 圆角 + 紧凑高度 |
| 输入框底色与边框 | 模板用 `--muted` 作底、`--border` 作描边 |
| 侧边栏配色 | 用 `--sidebar` / `--sidebar-accent` |
| 表格行高与分隔线 | 用 `--border`，行内用 4px 级间距 |
| 聊天气泡与引用卡片 | 引用卡片用 `--accent` 高亮 + 虚线边框 |
| 去掉 Streamlit 默认卡片阴影 | 模板为无阴影设计（A-04） |
| 保留键盘焦点可见 | 所有可聚焦元素（按钮、输入框、链接、**自定义可点击卡片**）必须保留可见焦点样式，使用 `--ring`（2px 实线或 outline），**不得整体 `outline:none`**（DR-13） |

### 8.3 主题变量落地

`colors_and_type.css` 里的变量名（`--primary` / `--background` …）与 Streamlit 生成的选择器互不冲突，可直接注入到 `theme.py` 的 `<style>` 里，作为全站统一真源。

**仅注入浅色令牌**，模板的 `.dark` 块不注入（本期不做暗色，见 A-05）。

## 9. 已知取舍

| 项 | 说明 |
| --- | --- |
| 高保真 vs 可实现 | 原型 HTML 是自由布局，Streamlit 组件范式受限；气泡右对齐、表格列宽等细节会近似实现，不追求像素一致 |
| 移动端 | 按既定策略「能用即可」；侧边栏在窄屏折叠，不做专门适配 |
| 中文字体 | 模板未含中文字体文件，依赖系统字体（macOS 苹方 / Windows 雅黑），跨平台字重会有细微差异 |
| 模板组件为推断生成 | 模板自述「组件由令牌反推」，非原始组件稿；实现以 `colors_and_type.css` 与 preview 页为准 |
| **不做暗色模式** | 客户裁决仅做浅色。模板 `.dark` 令牌留档备查，不实现；后续若要做需走变更流程 |
