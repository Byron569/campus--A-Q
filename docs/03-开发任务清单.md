## 8. 执行约定

1. **里程碑冻结**：每个里程碑开发期间需求冻结，新想法记入「待评估变更」，下个里程碑开头处理。
2. **完成后暂停**：每个里程碑结束即暂停，提交给客户验收，通过后进入下一个。
3. **提交规范**：Conventional Commits（`feat` / `fix` / `docs` / `refactor` / `test` / `chore`）。
4. **不提交敏感文件**：`.env`、`data/`、`backups/`、`.idea/` 一律忽略。
5. **命令执行**：开发期由 AI 直接在本机执行 `venv` / `pip` / `git` / `pytest` 等命令；客户可随时要求改为「只列命令、自己执行」。
