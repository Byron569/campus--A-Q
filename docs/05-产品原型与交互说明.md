## 2. 全局交互规则

| 编号 | 规则 | 说明 |
| --- | --- | --- |
| G-01 | 登录守卫 | 未登录访问任意页面 → 一律重定向到 PG-01 |
| G-02 | 角色守卫 | `user` 访问 PG-04 → 拦截并回到 PG-02，提示「无权访问该页面」 |
| G-03 | 侧边栏 | PG-02~PG-06 共用左侧导航；`user` 角色不显示「管理员页」入口 |
| G-04 | 默认落地 | 登录成功 → 进 PG-02；刷新页面保持当前页 |
| G-05 | 空态 | 无数据时必须给引导文案，不留白（见 §4） |
| G-06 | 错误提示 | 校验错误就地提示在字段下方；系统错误用顶部条提示，不暴露堆栈 |
| G-07 | 加载态 | 超过 300ms 的操作显示加载指示；问答用流式输出替代加载动画 |
| G-08 | 危险操作 | 删除、注销、禁用均需二次确认 |

## 3. 逐页交互说明

### PG-01 登录 / 注册页

| 元素 | 动作 | 结果 | 需求 |
| --- | --- | --- | --- |
| 用户名输入框 | 输入 | 失焦时校验长度与空值 | FR-01 |
| 密码输入框 | 输入 | 失焦时校验 ≥6 位 | FR-01 |
| 「我已阅读并同意《用户协议与隐私说明》」 | 勾选 | **未勾选时注册按钮不可用**；点击协议名弹出说明弹窗 | FR-28 |
| 「登 录」按钮 | 点击 | 校验 → 成功进入 PG-02；失败就地提示「用户名或密码错误」 | FR-02 |
| 「还没有账号？去注册 →」 | 点击 | 切换到注册表单（同页切换，不改 URL） | FR-01 |
| 注册表单「注册」按钮 | 点击 | 校验（用户名唯一 / 密码≥6 / 两次一致 / 已勾选）→ 成功即自动登录并进 PG-02 | FR-01 |
| 登录失败 ×3 次 | — | 仍只提示「用户名或密码错误」，不提示账号是否存在 | FR-02 |

**关键分支**：被禁用账号登录 → 提示「账号已被禁用，请联系管理员」，不进 PG-02。

### PG-02 问答页

| 元素 | 动作 | 结果 | 需求 |
| --- | --- | --- | --- |
| 左侧会话列表 | 点击某会话 | 加载该会话历史消息 | FR-12 |
| 「＋ 新建会话」 | 点击 | 建空会话并置为当前；标题暂显「新会话」 | FR-12 |
| 会话名 | 右键 / 悬停 | 出现「重命名 / 删除」；删除需二次确认 | FR-12 |
| 分类过滤下拉 | 选择 | 下次提问按该分类检索；默认「全部」 | FR-14 |
| 输入框 | 回车 / 点发送 | 提交问题；用户消息立即上屏 | FR-08 |
| 发送后 | — | 检索中显示「正在检索资料…」→ LLM 流式输出答案 | FR-08 |
| 答案渲染后 | — | 下方展示引用卡片；解析 `【来源N】` 与卡片一一对应 | FR-09 |
| 引用卡片 | 点击「展开原文」 | 展开该片段完整原文，可核对 | FR-09 |
| 检索无结果 | — | 输出固定拒答文案「知识库中暂无相关资料，建议咨询学生工作处。」**不显示引用卡片** | FR-10 |
| LLM 不可用 | — | 降级：直接展示检索到的原文片段 + 提示「模型服务暂不可用，以下为原始资料」 | FR-21 |
| 反馈按钮 | 点击有用 / 没用 | 落库；按钮变为已选态，不可重复提交 | FR-18 |
| 追问 | 直接再问 | 系统先做 Query 改写再检索，无需用户重述背景 | FR-11 |
| 「复制答案」 | 点击 | 复制答案正文 + 引用来源到剪贴板，提示「已复制」 | FR-19 |
| 「导出会话」 | 点击 | 下载当前会话为 `.md` 文件 | FR-20 |

**输入校验**：空内容不可发送；长度 >500 提示「问题过长」。

### PG-03 我的文档

| 元素 | 动作 | 结果 | 需求 |
| --- | --- | --- | --- |
| 上传区 | 拖拽 / 点击选择 | 支持**多选**；校验类型（PDF/DOCX/TXT/MD）与大小（≤20MB） | FR-05 |
| 上传区 | 选入非法文件 | **单文件报错，不影响同批其他文件**；提示「不支持的文件类型：xxx」 | FR-05 |
| 分类下拉 | 选择 | 可选；留空归为「未分类」 | FR-05 |
| 「开始上传」 | 点击 | 每个文件建独立入库任务，列表出现对应行 | FR-06 |
| 进度条 | — | 随 `done_chunks / total_chunks` 实时推进 | FR-06 |
| 失败行 | 点击「重试」 | 重新入库该文件；**不自动重试** | FR-06 |
| 失败行 | 悬停 | 展示失败原因（解析失败 / 未提取到文本 / 加密文件） | FR-06 |
| 列表 | 翻页 | 每页 10 条（可配置） | FR-13 |
| 「删除」 | 点击 | 二次确认 → 删除文档 + 级联清理向量 + 删原始文件 | FR-13 |

**图片型 PDF**：入库成功后若检测为疑似扫描件，行内追加提示「该文件疑似扫描件，建议后续启用 OCR」。

### PG-04 管理员页

| 元素 | 动作 | 结果 | 需求 |
| --- | --- | --- | --- |
| 「公共文档 / 用户管理」页签 | 切换 | 切换下方内容区 | FR-15/16 |
| 公共文档上传区 | 拖拽 / 选择 | 与 PG-03 同流程，但 **`is_public=1`、`user_id=NULL`** | FR-15 |
| 公共文档分类下拉 | 选择 | **必选**，未选不允许提交 | FR-15 |
| 公共文档「删除」 | 点击 | 二次确认 → 删除并对全员不可见 | FR-15 |
| 用户列表「禁用」 | 点击 | 二次确认 → 该账号无法登录 | FR-16 |
| 用户列表「启用」 | 点击 | 恢复该账号登录权限 | FR-16 |
| 用户列表「删除」 | 点击 | 二次确认（提示将级联删除其全部数据）→ 执行删除 | FR-16 |

**二期范围**：五维统计（FR-17）已移出本期，页面不出现统计区。

### PG-05 设置

| 元素 | 动作 | 结果 | 需求 |
| --- | --- | --- | --- |
| 显示名输入 + 「保存」 | 点击保存 | 更新显示名，提示「已保存」 | FR-26 |
| 新密码输入 + 「修改」 | 点击 | 需先验证旧密码；新密码 ≥6 位；成功后提示「密码已更新」 | FR-26 |
| 「注销账号」 | 点击 | **二次确认**，勾选「我已知晓数据不可恢复」后才可执行 | FR-25 |
| 注销执行 | — | 级联删除个人文档、向量、会话、反馈 → 退出登录回 PG-01 | FR-25 |
| 注销失败 | — | 提示「注销失败，请重试」；**不留下半删状态** | FR-25 |

### PG-06 关于 / 隐私说明

| 元素 | 动作 | 结果 | 需求 |
| --- | --- | --- | --- |
| 页面内容 | 进入 | 展示产品说明、数据使用说明、日志保留策略、学校联系方式（均来自配置） | FR-28 |
| 学校联系方式 | — | 读取 `knowledge_base.yaml` 的 `school.contact` | FR-27 |

## 4. 空态与边界态

| 场景 | 表现 |
| --- | --- |
| 会话无消息 | 「问点什么吧，比如：搬宿舍需要提前申请吗？」 |
| 会话列表为空 | 「还没有对话，点上方 ＋ 新建」 |
| 文档列表为空 | 「还没有文档，上传学生手册或通知试试」 |
| 公共文档为空（管理员） | 「还没有公共文档，上传后可被所有学生检索」 |
| 检索无命中 | 固定拒答文案（FR-10），无引用卡片 |
| LLM 降级 | 原文片段 + 「模型服务暂不可用」提示（FR-21） |
| 入库失败 | 行内红字原因 + 「重试」按钮（FR-06） |

## 5. 原型文件说明

| 项 | 内容 |
| --- | --- |
| 路径 | `docs/prototype/campus-qa-prototype.html` |
| 打开方式 | 双击用浏览器打开，无需服务器 |
| 内容 | 6 个页面可点击切换；含登录守卫模拟、会话切换、引用卡片展开、入库进度动画、二次确认弹窗 |
| 用途 | 演示交互流程、确认布局；**不参与代码实现** |
| 与实现的关系 | 实际实现为 Streamlit，布局按 Streamlit 组件范式落地；原型用于对齐信息层级与交互顺序 |
| 配色 | 采用 Doubao Design Library 令牌（`docs/07`），仅浅色模式 |
